# WoT Radio Voice — исходный проект VST3

Настраиваемый голосовой эффект в стиле узкополосной танковой/полевой радиосвязи.
Это **исходный проект**, а не уже собранный бинарный VST3.

## Возможности

- Distortion — мягкий перегруз/сатурация.
- Radio Tone — меняет полосу радиофильтра.
- Noise — добавляет тихий радиошум.
- Crackle — редкие короткие щелчки-помехи.
- Compression — упрощённая динамическая компрессия.
- Mix — баланс сухого и обработанного сигнала.
- Output — выходной уровень.
- Включение/выключение эффекта; параметры сохраняются в состоянии плагина.

## Сборка под Windows 64-bit

Нужны:
- Visual Studio 2022 с workload **Desktop development with C++**;
- CMake 3.22 или новее;
- Git;
- интернет при первой сборке (CMake скачает JUCE 8.0.6).

Откройте x64 Native Tools Command Prompt for VS 2022 в папке проекта и выполните:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

После успешной сборки VST3 будет в каталоге примерно такого вида:

`build/WoTRadioVoice_artefacts/Release/VST3/WoT Radio Voice.vst3`

Скопируйте bundle в:

`C:\Program Files\Common Files\VST3\`

Затем перезапустите Wave Link и выполните сканирование VST3-плагинов, если оно требуется вашей версией Wave Link.

## Важно

- Проект использует JUCE 8.0.6. Ознакомьтесь с лицензией JUCE и выберите подходящий вариант лицензирования для своего использования.
- Это первая версия DSP: шум/треск синтезируются процедурно, а компрессор намеренно простой. Начните с умеренных значений, особенно Noise и Crackle.
- Если Wave Link не показывает VST3, проверьте поддержку сторонних VST3 именно вашей версией Wave Link и разрядность хоста.
- Никакие сторонние EXE/DLL в архив не вложены. Сборка выполняется локально из исходников.


## Сборка без установки Visual Studio на ваш компьютер (GitHub Actions)

В проект добавлен workflow `.github/workflows/build.yml`. GitHub собирает VST3 на облачном Windows runner.

1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте пустой репозиторий на GitHub.
3. Загрузите в него содержимое этого ZIP (включая скрытую папку `.github`).
4. Откройте вкладку **Actions** репозитория.
5. Выберите **Build WoT Radio Voice VST3** и нажмите **Run workflow**.
6. Когда сборка завершится успешно, откройте запуск и скачайте artifact `WoT-Radio-Voice-VST3-Windows-x64`.
7. Распакуйте ZIP artifact. Папку `WoT Radio Voice.vst3` скопируйте в `C:\\Program Files\\Common Files\\VST3\\`.

Никакой Visual Studio на локальном ПК устанавливать не нужно. GitHub Actions использует облачный Windows runner. Первая сборка скачивает JUCE из официального GitHub-репозитория, поэтому runner нужен с доступом в интернет.
