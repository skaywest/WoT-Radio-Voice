WoT Radio Voice 2.0
Обновлённая версия эффекта радиопереговоров для Windows VST3.
Что изменено
Более узкая полоса радиосвязи (примерно 420–2400 Гц в зависимости от Radio Tone).
Более заметная сатурация передатчика.
Регулируемая грубая цифровая фактура/понижение частоты обновления сигнала.
Более сильная компрессия.
Более слышимый регулируемый шум и потрескивание.
Стартовые значения настроек сделаны более выраженными.
Сборка
Проект использует JUCE 8.0.6 и CMake. GitHub Actions workflow собирает VST3 на Windows Server 2022 и публикует артефакт.
Важно
Это стилизованный эффект радиостанции, а не точная копия исходного аудиотракта World of Tanks. После установки проверьте уровень громкости и уменьшите Output при необходимости.
